# Project rules

## Language: English only
Everything written into this repository must be in English:
- code, comments, docstrings, log and error messages
- notebooks (markdown and code), figure titles, axis labels and legends
- file names, column names, variable names
- README and docs
- commit messages and pull request texts

Exceptions: proper names and keys that come from external source data (e.g. series names in the
energy-charts files such as "Graubünden").

Replies in the chat may be in the user's language (German).

## Attribution
Do not add Claude attribution (Co-Authored-By trailers, "Generated with Claude Code") to commits or
pull requests.

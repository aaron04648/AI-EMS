REFERENCES – AI-EMS: market analysis and 24h price forecast Switzerland
=========================================================================
As of / data retrieval: 22 Oct 2026
Period considered: 01 Jan 2024 to 23 Oct 2026 (hourly, timestamps UTC)


A) DATA SOURCES (loaded automatically via API, analysis/01_fetch_data.py)
-------------------------------------------------------------------------

[1] Energy-Charts REST API, Fraunhofer Institute for Solar Energy Systems ISE, Freiburg.
    https://api.energy-charts.info/   (Swagger documentation, no API key)
    License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/), original source stated per series.
    Endpoints used:
      - /price?bzn=CH | DE-LU | FR | IT-North | AT
            Day-ahead exchange electricity prices (EUR/MWh), 60 min, or 15 min from 01 Oct 2025.
            Model target = CH day-ahead.
      - /public_power?country=ch | de | fr | it | at
            Public net electricity generation by energy source, load, residual load,
            renewable share of load and generation (MW or %).
      - /public_power_forecast?country=..&production_type=solar|wind_onshore|wind_offshore|load
            &forecast_type=day-ahead
            Day-ahead forecasts of the grid operators for solar, wind and load (MW).
            (The primary data comes from the ENTSO-E Transparency Platform, see [6].)
      - /cbet?country=ch
            Cross-border physical electricity exchange of Switzerland per neighbouring country (GW).
    Note: /signal (green power traffic light) only provides the current or next day, no history;
    for the analysis "Renewable share of load" from /public_power is used instead.

[2] Open-Meteo Previous Runs API (weather forecasts as they were available on the previous day).
    https://open-meteo.com/en/docs/previous-runs-api
    Endpoint: https://previous-runs-api.open-meteo.com/v1/forecast  (variables *_previous_day1)
    Variables: temperature_2m, shortwave_radiation, cloud_cover, wind_speed_100m, precipitation
    Points: Zurich, Bern, Geneva, Lugano, Sion, Munich, Hamburg.
    License: CC BY 4.0, "Weather data by Open-Meteo.com" (https://open-meteo.com/en/license).
    Underlying weather models (best_match): among others MeteoSwiss ICON-CH1/CH2, DWD ICON, ECMWF IFS.
    MeteoSwiss model data: https://open-meteo.com/en/docs/meteoswiss-api

[3] Swiss public holidays: Python package "holidays" 0.107 (vacanza), canton of Zurich.
    https://github.com/vacanza/holidays  (MIT license)

C) FURTHER (PRIMARY) SOURCES – not used via API, manual CSV download possible
-------------------------------------------------------------------------

[6] ENTSO-E Transparency Platform (primary source for prices, load and generation forecasts).
    https://transparency.entsoe.eu/
    API token only with a (free) account; Python package entsoe-py: https://github.com/EnergieID/entsoe-py
    CSV exports (login required, "Export Data" per page):
      - Day-ahead prices:                Transmission > Day-ahead Prices (Bidding Zone CH)
      - Load forecast:                   Load > Total Load - Day Ahead / Actual (Control Area CH)
      - Wind/solar forecast:             Generation > Generation Forecasts for Wind and Solar
      - Generation per energy source:    Generation > Actual Generation per Production Type

[7] Swissgrid – Energy overview Switzerland (load, production, exchange, 15 min, Excel per year):
    https://www.swissgrid.ch/en/home/operation/grid-data/generation.html

[8] Open Power System Data (OPSD) – cleaned European time series (until 2020):
    https://open-power-system-data.org/   or https://data.open-power-system-data.org/time_series/
